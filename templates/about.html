About Project

BSc Computer Science Final Year Project

What is SalaryPredict AI?

SalaryPredict AI is an end-to-end Machine Learning web application designed to predict an employee's salary based on several key factors. It serves as a practical demonstration of integrating AI models into a functional web interface.

Why Salary Prediction?

Predicting salaries is useful for HR departments to ensure fair compensation, for companies to budget accurately, and for potential employees to estimate their market value based on their experience and skills.

What is Multiple Linear Regression?

Multiple Linear Regression is a statistical technique that uses several explanatory variables to predict the outcome of a response variable. In this project, the response variable is Salary, and the explanatory variables are Age, Experience, Education, Job Level, Working Hours, and Previous Experience.

Technologies Used

  • Python: Core programming language.
  • Flask: Web framework for the backend.
  • Scikit-Learn: Machine learning library for building the regression model.
  • Pandas & NumPy: Data manipulation and mathematical operations.
  • HTML5/CSS3/JavaScript: Frontend design and interactivity.
  • Chart.js: Data visualization on the dashboard.

Advantages & Limitations

Advantages

  • Fast and simple prediction.
  • Interpretability of features.
  • Easy to deploy and use.

Limitations

  • Assumes linear relationship which might not always hold true.
  • Sensitive to outliers.
  • Dummy dataset used for demonstration.
